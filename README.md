# Site do LicitaBIM

Site institucional do **LicitaBIM** — licitações públicas com clareza, do edital ao contrato. Feito em Manaus, Amazonas.

Publicado pelo GitHub Pages: **https://regivaldsud.github.io/licitaobrasbim-site/**

Descreve a versão **6.3.0** do programa (repositório `regivaldsud/licitaobrasbim`).

- `index.html`, `styles.css`, `script.js` — página única, sem build.
- `img/` — capturas reais do programa, copiadas de `docs/img/` do repositório do programa (dados fictícios dos testes); `fonts/` — Inter e Material Symbols (licenças OFL e Apache 2.0).
- Configurações (download e WhatsApp) no topo de `script.js`.
